# NNMAP.SERVER

## Переменные CI/CD

| **Parameter Name**       | **Description**                             |
| ------------------------ | ------------------------------------------- |
| `DB_HOST`                | Адрес базы данных                           |
| `DB_PORT`                | Порт базы данных                            |
| `DB_LOGIN`               | Логин для подключения к базе данных         |
| `DB_PASSWORD`            | Пароль для подключения к базе данных        |
| `DB_NAME`                | Название базы данных                        |
| `SWAGGER_LOGIN`          | Логин для доступа к документации в Swagger  |
| `SWAGGER_PASSWORD`       | Пароль для доступа к документации в Swagger |
| `SWAGGER_PATH`           | Путь документации Swagger                   |
| `SCALAR_PATH`            | Путь документации Scalar                    |
| `SERVER_PORT`            | Порт сервера                                |
| `MAIL_USER`              | Почта для отправки писем                    |
| `MAIL_PASSWORD`          | Пароль для почты                            |
| `ENCRYPTION_KEY`         | Ключ для signature                          |
| `BASE_URL`               | Хост                                        |
| `JWT_ACCESS_TTL`         | TTL Токена Доступа                          |
| `JWT_REFRESH_SECRET_KEY` | Секретный ключ JWT Refresh                  |
| `JWT_ACCESS_SECRET_KEY`  | Секретный ключ JWT Access                   |
| `ADMIN_MAIL`             | Почта администратора                        |
| `PANEL_ADMIN_PASSWORD`   | Пароль администратора                       |
| `PANEL_ADMIN_LOGIN`      | Логин администратора                        |
| `WEBSOCKET_PATH`         | Путь документации websocket                 |
| `THROTTLER_TTL`          | Время жизни throttler                       |
| `THROTTLER_LIMIT`        | Лимит запросов throttler                    |
